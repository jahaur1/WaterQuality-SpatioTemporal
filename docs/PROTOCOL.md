# 数据与实验协议

更新日期：2026-11-10。

## 数据选择

原资料质量检查发现采集缺口，未把25个月全部当作连续序列。本次主要实验使用共同30天窗口2025-04-10 00:00至2025-05-10 00:00，750站、79,940条真实观测；9项核心水质指标在保留观测中无缺失，叶绿素与藻密度暂不使用。相邻观测不超过24小时，不是每4小时齐全的平衡面板。

9项工作分组：易测为水温、pH、溶解氧、电导率、浊度；化学为高锰酸盐指数、氨氮、总磷、总氮。分组依据检测便利程度，不表示化学4项不能在线测定。

原始数据及选定30天水质值不在Git中。数据SHA256等信息见数据集说明、摘要与来源清单。

## 预测协议

- 本站过去6条真实9项观测，不用未来化学值作为输入。
- 目标严格对齐起报时间+24小时，不用下一条记录替代。
- 条件分支读取目标时刻5项易测实测值，属于回溯已知条件；不能当作起报时未来易测未知的真实预报。
- 化学历史在每次起报时允许使用此前真实测量更新，不是长期停止化学检测。
- Chronos历史使用32个4小时槽位，只在6条实际历史覆盖范围内因果填充，最早历史之前填NaN；未来易测仅在+24小时槽位已知，中间槽位未知。
- 选择训练目标早于4月24日；时间验证目标在4月25日至4月29日前、起报不早于4月24日；重拟合训练目标早于4月29日；测试目标4月30日至5月10日00:00。
- 原测试23,136个配对，750站；单站最少9个、中位数13.5个，386站不足20个。

## 模型与拓扑

从逐站线性/深度模型、预训练模型和官方LoRA，逐步扩展到750节点联合潜在表示图模型。图实验使用Graph WaveNet作者传播与融合组件，时间编码仍由Chronos-2承担；不等于完整原版Graph WaveNet时序架构。

相关图仅用训练期同流域同步观测；距离图来自粗估位置；河网图使用候选河段的有向可达性，位置仍未人工确认。时滞图仅用训练期标签选0/4/8/12/24小时，标签为接收站t+24小时值，源为邻站t−lag值，两跳滞后累加。

不同组实验的空间输入、头结构、LoRA位置和训练预算可能不同，不能将所有报告按单一排行榜比较。官方单站LoRA为500步；后续多数组图探索为24步，两者不是匹配预算对照。

## 指标

逐站逐指标计算MAE、RMSE与R²，统一非负截断的组按其报告执行。近常数目标R²不定义；有效站数依指标不同。保留有限负R²，不截断为0、不删除极端负值。总体R²为四项指标各自逐站平均后等权平均。

“任一项R²＞0.5/0.8”的站数按站点去重，不是四项全部达标，也不是业务成功率。Pearson相关性不等于可推导性、预测精度、因果性或检测替代能力。

本测试区间已反复查看。下一阶段需要更多训练、时间验证、多随机种子、持续性基线、降低化学更新频率测试和新的时间留出区间。
