# WaterQuality-SpatioTemporal

**多流域、多站点水质时空预测：易测指标、历史化学观测与跨站信息的联合建模。**

Multi-station water-quality conditional forecasting with easy-to-measure indicators, historical chemical observations, and spatiotemporal relationships.

当前研究快照：**2026-11-12**。此仓库保存现有实验代码、适配记录、配置、派生统计表、实验报告与文献核查，保留本地实验目录名。30 天 750 站实测表、区间边界辅助观测和 4 小时线性插值表已随仓库发布。25 个月原始采集、预训练及训练后权重、预测缓存和河网地图不随仓库发布。

## 研究任务

| 项目 | 当前设置 |
|---|---|
| 基础数据 | 750站、79,940条真实观测，13流域、30省份 |
| 时间 | 2025-04-10 00:00至2025-05-10 00:00，持续30天 |
| 易测5项 | 水温、pH、溶解氧、电导率、浊度 |
| 化学4项 | 高锰酸盐指数、氨氮、总磷、总氮 |
| 当前主要任务 | 输入本站历史9项、目标时刻5项易测实测，预测精确24小时后的4项化学值；部分实验增加邻站历史 |
| 化学历史更新 | 每次起报可使用此前已测得的化学值 |
| 测试配对 | 23,136个，覆盖全部750站 |

这是**目标时刻易测实测可得的回溯条件预测**。它与起报时未知未来协变量的提前预报、完全不再检测化学指标的软测量任务不同。相关性强或R²过某个门槛均不等于可以替代检测。检测成本节省尚需低频化学更新与业务误差标准验证。

30天“连续”指所选站点相邻可用观测间隔不超过24小时，不表示逐小时齐全、等间隔或所有站同刻观测。[详细实验协议](docs/PROTOCOL.md)

## 最新结果

以下为固定24次更新下的匹配对照，平均R²为各指标逐站均值再四项等权平均，负值保留。“＞0.5/0.8”按任一指标达标的站点去重。

### 本站适配与跨站信息

| 模型 | 平均R² | 任一项R²＞0.5 | 任一项R²＞0.8 |
|---|---:|---:|---:|
| 冻结模型，同编码路径重新评估 | −0.785235 | 185 | 23 |
| 本站LoRA，24步 | −0.745295 | 186 | 22 |
| 本站LoRA＋校正，完全无邻站 | −0.396456 | 171 | 15 |
| 同结构：相关图＋单位分支＋自适应图 | −0.356348 | 171 | 14 |

本轮嵌套对照中，本站校正模块的平均收益最大；邻站额外提高平均R²约0.0401，但没有增加高分站数。无邻站组3条图消息路径全部只连接自身，已做邻站输入扰动检查。不同模型间净差值包含重新训练及模块交互，不是独立因果贡献百分比。

### 当前值与学习时滞

此组统一使用化学实测值的时滞空间分支，与上表的隐藏表示分支不同，应在组内比较。

| 模型 | 平均R² | 任一项R²＞0.5 | 任一项R²＞0.8 |
|---|---:|---:|---:|
| 无邻站 | −0.453913 | 146 | 8 |
| 邻站当前值 | −0.402498 | 155 | 12 |
| 邻站训练期选择的滞后值 | −0.400154 | 156 | 12 |

6,484条站点—指标关系中，1,384条选择非零滞后（4、8、12、24小时），涉及571个接收站。保持边与权重一致后，时滞额外提高平均R²约0.00234，增益较小。统计时滞不等于已确认的水流传播时间。

## 使用方式

先阅读[复现和本地资源说明](docs/REPRODUCIBILITY.md)。本仓库是研究快照，**没有打包完整运行环境与输入缓存**；30 天水质表已在仓库内，重新训练仍需补齐预训练权重、配对索引、第三方依赖和本地缓存。运行环境参考`requirements-core.txt`及`docs/ENVIRONMENT.md`。

```powershell
python tools/verify_snapshot.py
python tools/summarize_results.py
```

已有完整本地工作目录的用户，可以先查看资源连接计划：

```powershell
python tools/link_local_assets.py --workspace "D:\path\to\original_workspace"
# 确认路径后，增加 --apply 创建链接；不会上传或覆盖已有文件。
```
